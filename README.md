# Alura Plus

Página estática desenvolvida durante o curso **HTML e CSS: praticando HTML e CSS**, da Alura.

O projeto apresenta uma landing page do Alura Plus, uma plataforma de streaming com conteúdos educacionais da Alura. A página divulga o Combo+, reúne seções sobre formas de assistir, download de cursos, dispositivos compatíveis e informações de rodapé.

## Deploy

- GitHub Pages: https://dinalima1610.github.io/alura-plus/
- Vercel: https://alura-plus-dinalima1610.vercel.app/

 ## Funcionalidades

  - Apresenta a oferta do Combo+, com links para assinatura
  - Exibe uma seção sobre formas de assistir ao Alura Plus em diferentes dispositivos
  - Divulga o acesso conjunto ao Alura+ e ao Alura Língua pelo Combo+
  - Apresenta a possibilidade de baixar cursos para assistir sem internet
  - Lista os dispositivos favoritos compatíveis: TV, computador e celular
  - Exibe links informativos no rodapé, como idioma, dispositivos compatíveis, contrato de assinatura, política de privacidade, proteção de dados no Brasil, anúncios personalizados e ajuda
  - Layout responsivo para diferentes tamanhos de tela
  - Disponibiliza links de acesso ao projeto publicado no GitHub Pages e na Vercel

## Tecnologias utilizadas

- HTML5
- CSS3

## Conteúdos praticados

- Estrutura base de uma página HTML
- Uso de tags semânticas, como `main`, `section`, `footer`, `ul`, `li`, `h1`, `h2`, `h3`, `p`, `a` e `img`
- Organização de estilos com CSS
- Variáveis CSS para cores e fonte
- Importação de fonte externa pelo Google Fonts
- Uso de classes com padrão semelhante ao BEM (Block, Element e Modifier)
- Criação e estilização de botões com links
- Aplicação de imagens no HTML e imagem de fundo pelo CSS
- Construção de layout com CSS Grid
- Alinhamento de elementos com Flexbox
- Uso de `margin`, `padding` e unidades relativas
- Pseudo-classes `:hover` e `:active`
- Ajustes de responsividade com media query
- Publicação do projeto no GitHub Pages e na Vercel
